# Code of conduct

catscan follows the [Contributor Covenant, version 3.0](https://www.contributor-covenant.org/version/3/0/code_of_conduct/). It applies in every project space: issues, discussions, and any channel where you represent the project.

## Reporting

Report unacceptable behavior privately to the maintainers through the repository's **Security** tab (**Report a vulnerability** opens a private channel to them), and say that it is a conduct report. The maintainers review every report promptly and fairly and keep the reporter's privacy.

## Enforcement

The maintainers enforce the code with the steps the Contributor Covenant 3.0 describes, from a private warning up to a permanent ban, depending on the harm done.
