# @catscan/cli-darwin-arm64

The signed and notarized `catscan-core` binary for Apple silicon Macs (macOS 15 or later). It runs Apple Vision for catscan.

Do not install it directly: `@catscan/cli`, `@catscan/mcp` and `@catscan/playwright` install it automatically at the matching version.

```bash
npm install --save-dev @catscan/cli
```
